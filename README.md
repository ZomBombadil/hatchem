# Hatchem!

A family-friendly 2D egg-hatching game by **ZomBombadil**. Hatch eggs into collectible monsters across 5 rarity tiers, level them, evolve them, battle, and rip TCG-style booster packs. Single offline HTML file — no build step.

- **Play in browser:** https://zombombadil.github.io/hatchem/ (or open `index.html`)
- **Android:** install `Hatchem-v1.1.apk` (portrait, fully offline)

All creatures, names, and art are original. v1.1.
